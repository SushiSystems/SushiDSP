# Architecture

How SushiDSP's layers fit together as the tree stands today. Read [OVERVIEW.md](OVERVIEW.md)
first. [MODULES.md](MODULES.md) links each module under `modules/` to its own `README.md`,
which says which class does what and where the module departs from the design spec.

The core under `include/SushiDSP/` and `src/` has no README of its own; OVERVIEW.md describes
it. The READMEs under `tools/`, `applications/`, `assets/` and `tests/` are linked from the
[manual index](../README.md).
