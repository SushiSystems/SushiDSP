# SushiDSP D4 — JCM800 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the second SushiDSP product — a white-box Marshall JCM800 2203 amp (`modules/jcm800`) — with all six nonlinear stages the spec names present (V1a, V1b, V2a, the phase-inverter triode, and the two EL34 push-pull half-channels), a cabinet convolution stage that can load a real impulse response file (e.g. a DeCuir 4×12) from disk, and D4's roadmap "ships" bar: JCM800 in the rig host, plausibility-tested. This is the D4 phase from `docs/design/sushidsp.md` §5/§9.

**Architecture:** Every nonlinear stage reuses the `NewtonRaphsonSolver` pattern D2/D3 established (warm-started, bounded to prevent `exp()` overflow), but the *equation* for each is new to this plan. **Scope decision, documented explicitly:** the spec names "Koren/Norman" triode equations, which are SPICE curve-fit models requiring several tube-specific fitted constants (MU, EX, KG1, KP, KVB) normally extracted from datasheet curves this project has no access to — fabricating unvalidated fit constants would be less honest than an alternative. Every triode/pentode stage in this plan instead uses a **grid-conduction diode model**: the grid-cathode junction is modeled as a one-directional diode (physically real — a triode's grid genuinely draws current via a diode-like law once it swings positive of the cathode), solved by Newton-Raphson KCL exactly like D2/D3's diode stages, followed by a fixed linear (triode) or `tanh`-saturating (pentode) gain from grid to plate. This is a well-established technique in real-time tube-amp DSP modeling for exactly the reason above, and it keeps every stage the spec names present and audibly characterful (grid-conduction compression is the dominant nonlinearity in a real triode gain stage) without inventing unvalidated curve-fit numbers. Likewise the Marshall tone stack's DK-method 2-port network is approximated as a 3-band Biquad blend (Bass low-shelf, Mid peaking, Treble high-shelf) — the same documented simplification D3's tone crossfade already established and had reviewed, extended to three bands. The phase inverter's long-tailed-pair (a genuine 2-tube shared-cathode differential circuit) is approximated as one grid-conduction triode stage whose output is split into an inverted pair with a small bias offset between the two — a true LTP needs a 2-variable (Jacobian) nonlinear solve, and `NewtonRaphsonSolver` is scalar-only; extending it to vector form is out of this plan's scope (flagged for a future WDF-adaptor-tree phase, alongside D2's already-deferred series/parallel adaptors, if a later product genuinely needs it).

**Tech Stack:** C++17, CMake, GoogleTest — no new external dependencies (the WAV loader is hand-rolled, reading a subset of the PCM/IEEE-float WAV format sufficient for mono impulse responses; no libsndfile or similar).

**Spec:** `docs/design/sushidsp.md` (§5 JCM800, §7 products/wrappers, §8 repository layout, §9 D4, §0a reference header, §10 SOLID)

```cpp
    void Biquad::set_low_shelf(double sample_rate, double cutoff_hz, double gain_db, double q)
    {
        const double a = std::pow(10.0, gain_db / 40.0);
        const double omega = 2.0 * M_PI * cutoff_hz / sample_rate;
        const double sin_omega = std::sin(omega);
        const double cos_omega = std::cos(omega);
        const double alpha = sin_omega / (2.0 * q);
        const double two_sqrt_a_alpha = 2.0 * std::sqrt(a) * alpha;

        const double b0 = a * ((a + 1.0) - (a - 1.0) * cos_omega + two_sqrt_a_alpha);
        const double b1 = 2.0 * a * ((a - 1.0) - (a + 1.0) * cos_omega);
        const double b2 = a * ((a + 1.0) - (a - 1.0) * cos_omega - two_sqrt_a_alpha);
        const double a0 = (a + 1.0) + (a - 1.0) * cos_omega + two_sqrt_a_alpha;
        const double a1 = -2.0 * ((a - 1.0) + (a + 1.0) * cos_omega);
        const double a2 = (a + 1.0) + (a - 1.0) * cos_omega - two_sqrt_a_alpha;

        b0_ = static_cast<float>(b0 / a0);
        b1_ = static_cast<float>(b1 / a0);
        b2_ = static_cast<float>(b2 / a0);
        a1_ = static_cast<float>(a1 / a0);
        a2_ = static_cast<float>(a2 / a0);
    }

    void Biquad::set_high_shelf(double sample_rate, double cutoff_hz, double gain_db, double q)
    {
        const double a = std::pow(10.0, gain_db / 40.0);
        const double omega = 2.0 * M_PI * cutoff_hz / sample_rate;
        const double sin_omega = std::sin(omega);
        const double cos_omega = std::cos(omega);
        const double alpha = sin_omega / (2.0 * q);
        const double two_sqrt_a_alpha = 2.0 * std::sqrt(a) * alpha;

        const double b0 = a * ((a + 1.0) + (a - 1.0) * cos_omega + two_sqrt_a_alpha);
        const double b1 = -2.0 * a * ((a - 1.0) + (a + 1.0) * cos_omega);
        const double b2 = a * ((a + 1.0) + (a - 1.0) * cos_omega - two_sqrt_a_alpha);
        const double a0 = (a + 1.0) - (a - 1.0) * cos_omega + two_sqrt_a_alpha;
        const double a1 = 2.0 * ((a - 1.0) - (a + 1.0) * cos_omega);
        const double a2 = (a + 1.0) - (a - 1.0) * cos_omega - two_sqrt_a_alpha;

        b0_ = static_cast<float>(b0 / a0);
        b1_ = static_cast<float>(b1 / a0);
        b2_ = static_cast<float>(b2 / a0);
        a1_ = static_cast<float>(a1 / a0);
        a2_ = static_cast<float>(a2 / a0);
    }

    void Biquad::set_peaking(double sample_rate, double center_hz, double gain_db, double q)
    {
        const double a = std::pow(10.0, gain_db / 40.0);
        const double omega = 2.0 * M_PI * center_hz / sample_rate;
        const double sin_omega = std::sin(omega);
        const double cos_omega = std::cos(omega);
        const double alpha = sin_omega / (2.0 * q);

        const double b0 = 1.0 + alpha * a;
        const double b1 = -2.0 * cos_omega;
        const double b2 = 1.0 - alpha * a;
        const double a0 = 1.0 + alpha / a;
        const double a1 = -2.0 * cos_omega;
        const double a2 = 1.0 - alpha / a;

        b0_ = static_cast<float>(b0 / a0);
        b1_ = static_cast<float>(b1 / a0);
        b2_ = static_cast<float>(b2 / a0);
        a1_ = static_cast<float>(a1 / a0);
        a2_ = static_cast<float>(a2 / a0);
    }
```

**Interfaces:**
- Consumes: `SushiDSP::NewtonRaphsonSolver::solve` (D2).
- Produces: `SushiDSP::TriodeStage` with `TriodeStage(float source_resistance_ohms, float grid_leak_resistance_ohms, float cathode_bias_volts, float gain, float saturation_current_amps, float thermal_voltage_volts)`, `float process_sample(float input_voltage)`, `void reset()`. Tasks 6-7 consume this (V1a, V1b, V2a, and the phase-inverter triode are each one instance with different bias/gain parameters).

**Circuit derivation (grid-conduction diode model):** the grid node sees the previous stage through a coupling network with effective source resistance `Rs`, a grid-leak resistor `Rg` pulling toward the cathode-bias voltage `Vk`, and a one-directional diode-like grid-conduction current that only flows when the grid swings positive of the cathode (`Vg > Vk`). KCL: `f(Vg) = (Vg - Vin)/Rs + (Vg - Vk)/Rg + Is*(exp((Vg-Vk)/Vt) - 1) = 0`, `f'(Vg) = 1/Rs + 1/Rg + (Is/Vt)*exp((Vg-Vk)/Vt)`. Solved by `NewtonRaphsonSolver::solve`, warm-started from the previous sample, bounded to `[Vk - 60*Vt, Vk + 60*Vt]` (reusing D2/D3's `60*Vt` bound, applied around the bias point `Vk` rather than 0 since that's this stage's actual operating center). The plate output is the common-cathode stage's inverting linear gain: `Vout = -gain * (Vg - Vk)`.

```cpp
#pragma once

namespace SushiDSP
{
    /// @brief A common-cathode triode gain stage: grid-conduction diode nonlinearity solved by
    /// Newton-Raphson, followed by a fixed inverting linear plate gain. Used for V1a, V1b, V2a,
    /// and the phase-inverter triode in the JCM800 model.
    class TriodeStage
    {
    public:
        /// @param source_resistance_ohms Effective source resistance feeding the grid.
        /// @param grid_leak_resistance_ohms The grid-leak resistor to the cathode-bias voltage.
        /// @param cathode_bias_volts The stage's DC operating point (self-bias voltage).
        /// @param gain The common-cathode stage's inverting linear gain from grid to plate.
        /// @param saturation_current_amps Grid-conduction diode saturation current.
        /// @param thermal_voltage_volts Diode thermal voltage (~0.02585 V at room temperature).
        TriodeStage(
            float source_resistance_ohms, float grid_leak_resistance_ohms, float cathode_bias_volts,
            float gain, float saturation_current_amps, float thermal_voltage_volts);

        /// @brief Processes one sample through the stage.
        /// @param input_voltage The stage's input voltage for this sample.
        /// @return The inverted, gain-conduction-clipped plate output voltage.
        float process_sample(float input_voltage);

        /// @brief Resets the Newton-Raphson warm-start state to the cathode bias point.
        void reset();

    private:
        float source_resistance_;
        float grid_leak_resistance_;
        float cathode_bias_;
        float gain_;
        float saturation_current_;
        float thermal_voltage_;
        float voltage_limit_;
        float previous_grid_voltage_;
    };
}
```

```cpp
        float gain, float saturation_current_amps, float thermal_voltage_volts)
        : source_resistance_(source_resistance_ohms)
        , grid_leak_resistance_(grid_leak_resistance_ohms)
        , cathode_bias_(cathode_bias_volts)
        , gain_(gain)
        , saturation_current_(saturation_current_amps)
        , thermal_voltage_(thermal_voltage_volts)
        , voltage_limit_(60.0f * thermal_voltage_volts)
        , previous_grid_voltage_(cathode_bias_volts)
    {
    }

    float TriodeStage::process_sample(float input_voltage)
    {
        const float rs = source_resistance_;
        const float rg = grid_leak_resistance_;
        const float vk = cathode_bias_;
        const float is = saturation_current_;
        const float vt = thermal_voltage_;
        const float vin = input_voltage;

        auto residual = [rs, rg, vk, is, vt, vin](float vg)
        {
            return (vg - vin) / rs + (vg - vk) / rg + is * (std::exp((vg - vk) / vt) - 1.0f);
        };
        auto derivative = [rs, rg, vk, is, vt](float vg)
        {
            return 1.0f / rs + 1.0f / rg + (is / vt) * std::exp((vg - vk) / vt);
        };

        const float grid_voltage = NewtonRaphsonSolver::solve(
            residual, derivative, previous_grid_voltage_, 4,
            vk - voltage_limit_, vk + voltage_limit_);
        previous_grid_voltage_ = grid_voltage;

        return -gain_ * (grid_voltage - vk);
    }

    void TriodeStage::reset()
    {
        previous_grid_voltage_ = cathode_bias_;
    }
}
```

```cpp
#include <cmath>

#include "SushiDSP/math/NewtonRaphsonSolver.hpp"

namespace SushiDSP
{
    PentodeStage::PentodeStage(
        float source_resistance_ohms, float grid_leak_resistance_ohms, float cathode_bias_volts,
        float gain, float saturation_current_amps, float thermal_voltage_volts,
        float plate_saturation_drive)
        : source_resistance_(source_resistance_ohms)
        , grid_leak_resistance_(grid_leak_resistance_ohms)
        , cathode_bias_(cathode_bias_volts)
        , gain_(gain)
        , saturation_current_(saturation_current_amps)
        , thermal_voltage_(thermal_voltage_volts)
        , plate_saturation_drive_(plate_saturation_drive)
        , voltage_limit_(60.0f * thermal_voltage_volts)
        , previous_grid_voltage_(cathode_bias_volts)
    {
    }

    float PentodeStage::process_sample(float input_voltage)
    {
        const float rs = source_resistance_;
        const float rg = grid_leak_resistance_;
        const float vk = cathode_bias_;
        const float is = saturation_current_;
        const float vt = thermal_voltage_;
        const float vin = input_voltage;

        auto residual = [rs, rg, vk, is, vt, vin](float vg)
        {
            return (vg - vin) / rs + (vg - vk) / rg + is * (std::exp((vg - vk) / vt) - 1.0f);
        };
        auto derivative = [rs, rg, vk, is, vt](float vg)
        {
            return 1.0f / rs + 1.0f / rg + (is / vt) * std::exp((vg - vk) / vt);
        };

        const float grid_voltage = NewtonRaphsonSolver::solve(
            residual, derivative, previous_grid_voltage_, 4,
            vk - voltage_limit_, vk + voltage_limit_);
        previous_grid_voltage_ = grid_voltage;

        const float linear_plate = -gain_ * (grid_voltage - vk);
        return std::tanh(linear_plate * plate_saturation_drive_) / plate_saturation_drive_;
    }

    void PentodeStage::reset()
    {
        previous_grid_voltage_ = cathode_bias_;
    }
}
```

```cpp
#include "SushiDSP/io/WavFile.hpp"

#include <cstdint>
#include <cstring>
#include <fstream>
#include <stdexcept>

namespace SushiDSP
{
    namespace
    {
        uint32_t read_u32_le(const uint8_t* p) { return static_cast<uint32_t>(p[0]) | (static_cast<uint32_t>(p[1]) << 8) | (static_cast<uint32_t>(p[2]) << 16) | (static_cast<uint32_t>(p[3]) << 24); }
        uint16_t read_u16_le(const uint8_t* p) { return static_cast<uint16_t>(p[0] | (p[1] << 8)); }

        float pcm16_to_float(const uint8_t* p) { return static_cast<int16_t>(read_u16_le(p)) / 32768.0f; }

        float pcm24_to_float(const uint8_t* p)
        {
            int32_t value = static_cast<int32_t>(p[0]) | (static_cast<int32_t>(p[1]) << 8) | (static_cast<int32_t>(p[2]) << 16);
            if (value & 0x800000)
            {
                value |= static_cast<int32_t>(0xFF000000);
            }
            return static_cast<float>(value) / 8388608.0f;
        }

        float pcm32_to_float(const uint8_t* p)
        {
            const int32_t value = static_cast<int32_t>(read_u32_le(p));
            return static_cast<float>(value) / 2147483648.0f;
        }

        float ieee_float32_to_float(const uint8_t* p)
        {
            float value;
            std::memcpy(&value, p, sizeof(float));
            return value;
        }
    }

    std::vector<float> WavFile::load_mono(const std::string& path, double* out_sample_rate)
    {
        std::ifstream file(path, std::ios::binary);
        if (!file)
        {
            throw std::runtime_error("WavFile: could not open '" + path + "'");
        }

        std::vector<uint8_t> bytes(
            (std::istreambuf_iterator<char>(file)), std::istreambuf_iterator<char>());

        if (bytes.size() < 44)
        {
            throw std::runtime_error("WavFile: '" + path + "' is too small to be a valid WAV file");
        }
        if (std::memcmp(bytes.data(), "RIFF", 4) != 0 || std::memcmp(bytes.data() + 8, "WAVE", 4) != 0)
        {
            throw std::runtime_error("WavFile: '" + path + "' is not a RIFF/WAVE file");
        }

        std::uint16_t format_tag = 0;
        std::uint16_t channel_count = 0;
        std::uint32_t sample_rate = 0;
        std::uint16_t bits_per_sample = 0;
        const uint8_t* data_start = nullptr;
        std::uint32_t data_bytes = 0;

        std::size_t offset = 12;
        while (offset + 8 <= bytes.size())
        {
            char chunk_id[5] = { 0 };
            std::memcpy(chunk_id, bytes.data() + offset, 4);
            const uint32_t chunk_size = read_u32_le(bytes.data() + offset + 4);
            const std::size_t chunk_data_offset = offset + 8;

            if (chunk_data_offset + chunk_size > bytes.size())
            {
                throw std::runtime_error("WavFile: '" + path + "' has a truncated chunk");
            }

            if (std::memcmp(chunk_id, "fmt ", 4) == 0)
            {
                if (chunk_size < 16)
                {
                    throw std::runtime_error("WavFile: '" + path + "' has a malformed fmt chunk");
                }
                const uint8_t* fmt = bytes.data() + chunk_data_offset;
                format_tag = read_u16_le(fmt + 0);
                channel_count = read_u16_le(fmt + 2);
                sample_rate = read_u32_le(fmt + 4);
                bits_per_sample = read_u16_le(fmt + 14);
            }
            else if (std::memcmp(chunk_id, "data", 4) == 0)
            {
                data_start = bytes.data() + chunk_data_offset;
                data_bytes = chunk_size;
            }

            offset = chunk_data_offset + chunk_size + (chunk_size % 2);
        }

        if (format_tag != 1 && format_tag != 3)
        {
            throw std::runtime_error("WavFile: '" + path + "' uses an unsupported format tag (only PCM and IEEE float are supported)");
        }
        if (channel_count == 0 || data_start == nullptr)
        {
            throw std::runtime_error("WavFile: '" + path + "' is missing fmt or data chunk content");
        }

        const std::uint32_t bytes_per_sample = bits_per_sample / 8;
        const std::uint32_t frame_bytes = bytes_per_sample * channel_count;
        const std::uint32_t frame_count = frame_bytes > 0 ? data_bytes / frame_bytes : 0;

        std::vector<float> mono(frame_count, 0.0f);
        for (std::uint32_t frame = 0; frame < frame_count; ++frame)
        {
            float sum = 0.0f;
            for (std::uint16_t channel = 0; channel < channel_count; ++channel)
            {
                const uint8_t* sample_ptr = data_start + frame * frame_bytes + channel * bytes_per_sample;
                float sample_value = 0.0f;
                if (format_tag == 3 && bits_per_sample == 32)
                {
                    sample_value = ieee_float32_to_float(sample_ptr);
                }
                else if (format_tag == 1 && bits_per_sample == 16)
                {
                    sample_value = pcm16_to_float(sample_ptr);
                }
                else if (format_tag == 1 && bits_per_sample == 24)
                {
                    sample_value = pcm24_to_float(sample_ptr);
                }
                else if (format_tag == 1 && bits_per_sample == 32)
                {
                    sample_value = pcm32_to_float(sample_ptr);
                }
                else
                {
                    throw std::runtime_error("WavFile: '" + path + "' uses an unsupported bit depth for its format tag");
                }
                sum += sample_value;
            }
            mono[frame] = sum / static_cast<float>(channel_count);
        }

        if (out_sample_rate != nullptr)
        {
            *out_sample_rate = static_cast<double>(sample_rate);
        }

        return mono;
    }
}
```

```cpp
TEST(Unit_Dsp, Jcm800PreampIncreasesOutputEnergy)

    auto measure_rms = [](float preamp) -> float
    {
        SushiDSP::Jcm800 node;
        SushiDSP::PrepareInfo info{ 48000.0, 256, 1 };
        node.prepare(info);
        node.set_preamp(preamp);
        node.set_master(0.7f);
        node.set_bass(0.5f);
        node.set_middle(0.5f);
        node.set_treble(0.5f);
        node.set_presence(0.5f);

        std::vector<float> input(256);
        std::vector<float> output(256, 0.0f);
        const float* input_channels[1] = { input.data() };
        float* output_channels[1] = { output.data() };

        double sum_sq = 0.0;
        std::size_t count = 0;
        double global_index = 0.0;
        for (int block = 0; block < 30; ++block)
        {
            for (std::size_t i = 0; i < input.size(); ++i)
            {
                input[i] = 0.05f * std::sin(2.0 * M_PI * 220.0 * (global_index + i) / 48000.0);
            }
            global_index += 256.0;

            SushiDSP::ProcessContext context{ output_channels, input_channels, 256, 0.0 };
            node.process(context);

            if (block >= 15)
            {
                for (float sample : output)
                {
                    sum_sq += static_cast<double>(sample) * sample;
                    ++count;
                }
            }
        }
        return static_cast<float>(std::sqrt(sum_sq / static_cast<double>(count)));
    };

    const float low_preamp_rms = measure_rms(0.1f);
    const float high_preamp_rms = measure_rms(1.0f);

    EXPECT_GT(high_preamp_rms, low_preamp_rms);
```

```cpp
    void Jcm800::prepare(const PrepareInfo& info)
    {
        sample_rate_ = info.sample_rate;
        bright_cap_.set_high_pass(sample_rate_, kBrightCapHz, 0.707);
        coupling_cap_.set_high_pass(sample_rate_, kCouplingCapHz, 0.707);
        presence_shelf_.set_high_shelf(sample_rate_, kPresenceHz, (presence_current_ - 0.5f) * 2.0f * kMaxPresenceDb, 0.707);

        tone_stack_ = JcmToneStack(sample_rate_);
        output_transformer_ = OutputTransformerStage(sample_rate_, kOutputTransformerRolloffHz, kOutputTransformerLeakageHz, kOutputTransformerSaturationDrive);
        sag_ = PowerSupplySagStage(sample_rate_, kSagAmount, kSagRecoveryTimeSeconds);

        oversampler_a_ = std::make_unique<Oversampler8x>(info.max_block);
        oversampler_b_ = std::make_unique<Oversampler8x>(info.max_block);

        scratch_base_.assign(info.max_block, 0.0f);
        scratch_oversampled_a_.assign(static_cast<std::size_t>(info.max_block) * 8, 0.0f);
        scratch_oversampled_b_.assign(static_cast<std::size_t>(info.max_block) * 8, 0.0f);

        if (!cabinet_impulse_response_.empty())
        {
            cabinet_ = std::make_unique<PartitionedConvolution>(
                kCabinetPartitionSize, cabinet_impulse_response_.data(),
                static_cast<std::uint32_t>(cabinet_impulse_response_.size()));
            scratch_cabinet_.assign(kCabinetPartitionSize, 0.0f);
        }

        reset();
    }

    void Jcm800::process(ProcessContext& context)
    {
        preamp_current_ += (preamp_target_ - preamp_current_) * 0.1f;
        master_current_ += (master_target_ - master_current_) * 0.1f;
        presence_current_ += (presence_target_ - presence_current_) * 0.1f;
        presence_shelf_.set_high_shelf(sample_rate_, kPresenceHz, (presence_current_ - 0.5f) * 2.0f * kMaxPresenceDb, 0.707);

        const float* input = context.inputs[0];
        float* output = context.outputs[0];
        const std::uint32_t frames = context.frames;
        const std::uint32_t oversampled_frames = frames * 8;

        for (std::uint32_t i = 0; i < frames; ++i)
        {
            scratch_base_[i] = bright_cap_.process_sample(input[i] * preamp_current_ * normalized_to_gain(1.0f));
        }

        const float* upsampled_a = oversampler_a_->upsample(scratch_base_.data(), frames);
        for (std::uint32_t i = 0; i < oversampled_frames; ++i)
        {
            const float v1a_out = v1a_.process_sample(upsampled_a[i]);
            scratch_oversampled_a_[i] = v1b_.process_sample(coupling_cap_.process_sample(v1a_out));
        }
        oversampler_a_->downsample(scratch_oversampled_a_.data(), oversampled_frames, scratch_base_.data());

        for (std::uint32_t i = 0; i < frames; ++i)
        {
            scratch_base_[i] = tone_stack_.process_sample(scratch_base_[i]);
        }

        const float* upsampled_b = oversampler_b_->upsample(scratch_base_.data(), frames);
        for (std::uint32_t i = 0; i < oversampled_frames; ++i)
        {
            const float phase_split = v2a_.process_sample(upsampled_b[i]);
            const float phase_inverted = phase_inverter_.process_sample(phase_split);
            const float el34_a_out = el34_a_.process_sample(phase_inverted);
            const float el34_b_out = el34_b_.process_sample(-phase_inverted);
            scratch_oversampled_b_[i] = el34_a_out - el34_b_out;
        }
        oversampler_b_->downsample(scratch_oversampled_b_.data(), oversampled_frames, scratch_base_.data());

        for (std::uint32_t i = 0; i < frames; ++i)
        {
            float x = output_transformer_.process_sample(scratch_base_[i]);
            x = sag_.process_sample(x);
            x = presence_shelf_.process_sample(x);
            scratch_base_[i] = x * master_current_;
        }

        if (cabinet_)
        {
            cabinet_->process(scratch_base_.data(), output);
        }
        else
        {
            for (std::uint32_t i = 0; i < frames; ++i)
            {
                output[i] = scratch_base_[i];
            }
        }
    }
```
