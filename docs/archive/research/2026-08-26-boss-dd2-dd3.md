# Boss DD-2 / DD-3 Digital Delay — research dossier for a circuit-accurate model

Scope: the 1983–2002 DRAM-based units (DD-2 1983, DD-3 "long chip" 1986, DD-3A 1990/91, DD-3B 2002).
The 2014+ Taiwan DD-3 and the DD-3T are a different architecture (Roland DSP, no DRAM) and are out
of scope for a "1:1 of the thrash-era pedal" model.

Primary sources are the official Roland/Boss service notes, which include full circuit diagrams,
parts lists and the factory clock-adjustment procedure. Everything below is traced to a URL.

---

## 1. Architecture (from the official schematics)

### 1.1 Signal chain, DD-2 / DD-3 first edition (SEP 1986 service notes)

```
IN ─ JFET buffer (Q1 2SK30A-0) ─┬─────────────────────────── DIRECT jack (analog, always dry)
                                │
                                └─ BJT buffer (Q2 2SC732) ─ pre-emphasis ─ anti-alias LPF
                                   (Q3–Q6 2SC732, fc = 7 kHz) ─ compressor (½ NE570)
                                     │
                                     ├─ S/H (SAH) ─ comparator (µPC271C / NJM311D)
                                     │      └─ SAR loop against R-2R ladder ─── 12-bit ADC
                                     │
                                RDD63H101 custom LSI  ←→  3 × 64 Kbit DRAM (4164)
                                     │
                                     └─ 12-bit D0..D11 ─ R-2R ladder (RKM14L492-103F, 10k)
                                        ─ expander (½ NE570) ─ de-emphasis
                                        ─ reconstruction LPF (Q9–Q10 2SC732, fc = 7 kHz)
                                        ─ M5218 mixer ─┬─ F.BACK pot (VR2 50 kB) → back to
                                                       │   the *analog* input of the ADC chain
                                                       └─ E.LEVEL pot (VR3 50 kB) → mixer
                                                          ─ NJM5534 ─ JFET switches Q5/Q8
                                                          ─ MONO/OUTPUT jack
```

Source: <https://archive.org/details/boss_DD-2_DD-3_SERVICE_NOTES> (OCR text:
<https://archive.org/download/boss_DD-2_DD-3_SERVICE_NOTES/DD-2_DD-3_SERVICE_NOTES_djvu.txt>),
mirror <https://www.synfo.nl/servicemanuals/Boss/BOSS_DD-3_SERVICE_NOTES.pdf>.

Key structural facts for the model:

* **The dry path is fully analog and never converted** — spec'd 10 Hz–60 kHz. The DIRECT jack
  carries dry only, regardless of switching. Mixing is analog at the M5218/5534 stage.
* **The feedback loop is analog and wraps the entire converter chain.** Each repeat is
  re-compressed, re-band-limited to 7 kHz, re-quantised to 12 bits and re-expanded. This is why
  the repeats darken and grain up cumulatively like an analog BBD delay, and it is the single
  most important behaviour to reproduce. Multiple secondary sources state this explicitly
  ("redo the echoes each repeat, unlike newer pedals which just spit out the same bit samples"
  — <https://www.analogman.com/boss.htm>).
* **Companding is external analog** (NE570, both halves used: compressor in, expander out),
  not inside the LSI, plus **7 kHz pre/de-emphasis** around the loop.
  <http://falseelectronics.blogspot.com/2017/08/boss-dd-2.html>
* **The DAC is an external R-2R ladder driven by 12 parallel lines (D0..D11) from the LSI**, and
  the same ladder is reused by the LSI + external comparator + sample-and-hold as a successive-
  approximation ADC. (The LSI pinout in the circuit diagram shows D0–D11, DIN, DOUT, SAH.)
  Note: falseelectronics calls it "sigma-delta"; the schematic topology says SAR. Trust the
  schematic.
* **Anti-alias and reconstruction filters are discrete multi-transistor active LPFs**, not
  op-amp Sallen-Key, both labelled `fc = 7 kHz` on the factory diagram.
* **Power: single 9 V, no boost.** A µA78L05 / NJM78L05A makes +5 V for the digital side; audio
  runs off 9 V with a ½Vcc bias rail. Zeners RD5.1EB-3 and RD11FB-3. 45–65 mA draw.
* Bypass/mute: HD14066BP CMOS switches + 2SK30A JFET switches, BA634 flip-flop for the footswitch
  (DD-2/3), power-on muting via Q11–Q13 (~1.5 s mute).

### 1.2 The clock — this is the crux of the "range" behaviour

The factory adjustment procedure pins the numbers exactly.

DD-2 / DD-3 (1986 notes): VCO IC8 (74HC00-based) runs **1.28 MHz – 5.18 MHz**.
Adjust for sample period **T = 12.12 µs (82.5 kHz ± 0.4 kHz)** at the fast end, master clock
5.18 MHz ± 25.6 kHz; and **T = 50 µs (20 kHz ± 0.1 kHz)** at the slow end, MSCK 1.28 MHz ± 6.4 kHz.
So **fs = MSCK / 64**, continuously variable ≈ **20 kHz … 82.5 kHz**, set by the D.TIME knob.

DD-3A (1991 notes): same scheme, restated as **T = 12.5 ± 0.5 µs (80 kHz)** minimum and
**T = 50 ± 2 µs (20 kHz)** maximum, measured at R26 / IC3 pin 5.
<https://archive.org/download/boss_DD-3A_SERVICE_NOTES/DD-3A_SERVICE_NOTES_djvu.txt>

**Derived (and self-consistent) consequence:** the delay line is a *fixed sample count* per range;
delay time is varied purely by sweeping fs 4:1.

| Mode | Delay range | Sample count (derived) |
|---|---|---|
| S | 12.5–50 ms | ≈ 1000 (1024) |
| M | 50–200 ms | ≈ 4000 (4096) |
| L | 200–800 ms | ≈ 16000 (16384) |
| HOLD | 200–800 ms | as L, write disabled |

Check: 12.5 ms × 80 kHz = 1000; 50 ms × 20 kHz = 1000. Same for M and L. The LSI's `RAS16 /
RAS32 / RAS48 / RAS64` pins select how much DRAM is addressed, matching this.

**Memory arithmetic confirms 12 bits/sample exactly:** three 64 Kbit DRAMs = 196 608 bits;
16 384 samples × 12 bits = 196 608 bits. Exact fit. (DD-3A replaced the three 4164s with one
M5M4464L-12, 256 Kbit.)

**Modelling consequence that most people get wrong:** because the anti-alias/reconstruction
filters are fixed at 7 kHz while fs sweeps 20–82.5 kHz, the *audio bandwidth does not change with
the range switch or the time knob* — the published spec is 40 Hz–7 kHz for the delay sound in all
modes. What changes with fs is the quantisation-noise spectrum, the reconstruction stair-step
image content, and the residual clock feedthrough. There is essentially **no in-band aliasing**
even at the slowest clock (Nyquist 10 kHz vs a 7 kHz brickwall-ish filter). The DD-2/3's "lo-fi"
character comes from 12-bit + companding + the 7 kHz wall + repeated re-conversion, **not** from
aliasing.

Because the master clock is a single free-running VCO directly on the time knob, **turning D.TIME
pitch-shifts the buffered audio smoothly and glitch-free** — a tape-like warble. That is a
first-class feature to model (fractional-rate resampling of the whole loop, not a fixed-rate line
with an interpolating tap).

## 2. Revision history and what actually changes the tone

| Version | Date | Main IC | DRAM | Notes |
|---|---|---|---|---|
| DD-2 | 1983 | RDD63H101 | 3 × 4164 (64 Kbit) | Same LSI as Roland SDE-3000 |
| DD-3 "long chip" | 1986 | RDD63H101 | 3 × 4164 | *"The difference between DD-2 and DD-3 is nothing but the pedal"* — official parts list |
| DD-3A | Dec 1990 / Apr 1991 | MN51010RBA gate array | 1 × M5M4464L-12 | C1 0.027 → 0.047 µF, BJT buffer stage dropped, C18 removed |
| DD-3B | 2002 | MN51010RBA | M11B416256A-35T, SMD | No audible/topological change claimed |
| DD-3 (Taiwan) | 2014+ | Roland DSP | none | Different architecture |
| DD-3T | 2019 | DSP + tap tempo | none | Out of scope |

The 1986 service notes state flatly that DD-2 and DD-3 differ **only in the pedal treadle
part number** (2218053300 vs 2218054700). So a DD-2 model and an early-DD-3 model are the same
model. The DD-3A is the first genuine electrical change.

DD-3 → DD-3A tone-relevant deltas (<https://stompboxelectronics.com/2023/07/20/history-of-the-boss-dd-3/>):
* Input coupling cap C1 0.027 µF → 0.047 µF (more low end into the delay path).
* DD-3 fed the signal through a JFET *and* a BJT buffer; DD-3A goes straight off the JFET.
* C18 removed → direct coupling between pre-emphasis and the NE570 compressor.
* Some 10 µF/50 V electrolytics → 1 µF/16 V.
* Op-amp complement changes: DD-2/3 has M5218L + **NJM5534D** + µPC271C; DD-3A has M5218AL +
  **µPC4072HA** + NJM311D. Losing the 5534 is a plausible source of the "cleaner/brighter but
  less grainy" reputation, alongside the different gate array's internal conversion timing.

Consensus of listening reports: DD-2 and long-chip DD-3 are indistinguishable; DD-3A/B are
slightly cleaner and brighter, DD-2/early DD-3 warmer and grainier.
<https://www.guitarworld.com/gear/guitar-pedals/boss-dd-2-dd-3-digital-delay>,
<https://professornigels.com/blogs/news/boss-dd-2-or-dd-3-digital-delay-which-version-is-best-for-you>,
<http://www.bossareaforum.com/Forum/viewtopic.php?t=422>

## 4. Known measured / reported behaviour

* Delay sound is flat 40 Hz–7 kHz ±1/−3 dB **in every range**; the roll-off is a fixed analog
  filter, not a sample-rate artefact. (SN specs, A)
* Residual noise < −95 dBm IHF-A. Because of the compander + emphasis, the noise floor *pumps
  with the signal* rather than sitting still — classic companded-delay behaviour, and it is
  audible on the tail of each repeat. (SN spec A; behaviour B, from the general companded-delay
  discussion at <https://gearspace.com/board/electronic-music-instruments-and-electronic-music-production/978705-8-bit-12-bit-delays-2.html>)
* Repeats darken and grain progressively because the analog feedback loop re-runs the whole
  conversion chain each pass; DIY/repair and review sources consistently describe this as the
  DD-2/early-DD-3's defining "analog-like" trait.
  <https://www.analogman.com/boss.htm>, <https://www.musicradar.com/news/the-fx-files-boss-dd-3>
* Turning D.TIME while repeats are sounding gives smooth, glitch-free pitch bend (single VCO,
  no crossfade). <http://falseelectronics.blogspot.com/2017/08/boss-dd-2.html>
* Common failure mode: DRAM degradation producing distorted/noisy repeats — worth knowing so
  you don't accidentally model a broken unit's "vintage grit". (same source)
* I found **no rigorous published measurement set** (no impulse responses, no swept-sine plots,
  no THD-vs-level curves). YouTube A/Bs exist but are not measurements:
  <https://www.youtube.com/watch?v=hvKpllAL9m4>, <https://www.youtube.com/watch?v=e7lEBDvlhBU>

## 6. Where the 1:1 claim breaks, and how to close each gap

Everything **outside** the LSI is fully documented and can be modelled from the schematic:
JFET/BJT buffers, pre/de-emphasis, both 7 kHz discrete filters, the NE570 compander, the R-2R
ladder, the analog mix and the analog feedback loop. That is most of the tone.

What is unknowable from paper:

1. **The LSI's internal conversion timing and any internal filtering.** We know it is 12-bit and
   drives an external ladder, but not the SAR settling behaviour, whether there is any internal
   dithering, oversampling, or interpolation, and not the exact DAC output hold/glitch shape.
   *Measurement:* swept-sine and impulse into the wet-only path (E.LEVEL max, F.BACK zero,
   DIRECT unplugged so MONO carries dry+wet, or use STEREO mode where MONO carries **delay only**
   — the 1986 notes document exactly this: plugging DIRECT and engaging the footswitch puts the
   wet signal alone on MONO). Capture at 192 kHz, at several D.TIME settings per range.
2. **R-2R ladder trimming and monotonicity.** A cheap 10 k network has real DNL; that is part of
   the grain. *Measurement:* THD+N vs input level at, say, 20 points from −60 to 0 dBFS-equivalent,
   wet path only, plus a low-level sine to expose the quantisation staircase.
3. **Exact anti-alias/reconstruction filter transfer functions.** The schematic only labels
   "fc = 7 kHz"; the discrete 4-transistor topology's order and Q are not stated, and the OCR'd
   values are incomplete. *Measurement:* swept sine on the wet path at the **fastest** clock
   (D.TIME min, S mode) so the converter is maximally transparent and what you see is the analog
   filters; fit an IIR to the magnitude *and phase*.
4. **NE570 time constants as actually wired** (attack/release caps set the pumping rate).
   *Measurement:* tone burst at several levels, measure envelope of the wet output; or read C19,
   C25, C20 off a real board.
5. **Sample-count per range** is derived, not printed. *Measurement:* impulse in, measure delay
   time at both clock extremes in each mode; N = fs·τ should come out constant.
6. **Component values not resolved by OCR.** Fix by getting a high-resolution scan of page 3 of
   the 1986 service notes, or photographing a board.

### Recommended modelling strategy

Model it as a **variable-rate loop**, not a fixed-rate delay line. Concretely:

1. Run the analog stages (buffers, emphasis, both 7 kHz filters, NE570, mixer) at host rate as
   ordinary circuit models.
2. Between the compressor and the expander, resample to the pedal's instantaneous fs
   (20–82.5 kHz, driven by D.TIME with the documented 4:1 law), quantise to 12 bits, run a
   fixed-length circular buffer of 1000/4000/16000 samples, then resample back. The VCO rate
   should be a smoothly-varying control signal so time-knob sweeps pitch-bend naturally.
3. Close the feedback loop **around the whole thing in the analog domain** — that, plus the
   12-bit re-quantisation each pass, is what produces the signature decay.
4. Ship a single model for DD-2 / early DD-3 (they are electrically identical per Boss), and
   treat DD-3A as a variant with three or four component/topology deltas.
5. Book the five measurements above against a real unit before claiming 1:1; without them the
   honest claim is "schematic-accurate outside the LSI, parametric inside it".
