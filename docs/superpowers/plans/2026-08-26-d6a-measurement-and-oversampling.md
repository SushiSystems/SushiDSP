# D6a — Measurement Infrastructure and Oversampling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every later phase a numeric acceptance test (`tests/measure/`, full-block golden files, a SPICE reference corpus) and replace the 15-tap Hamming halfbands with ≥ 90 dB Parks–McClellan halfbands applied in polyphase form, collapsing the JCM800 to one oversampled region.

**Architecture:** Measurement code is header-only under `tests/measure/` and is never linked into a product. Halfband coefficients are generated once by `tools/dsp/design_halfband.py` (scipy `remez`) and committed as `inline constexpr` arrays in `include/SushiDSP/math/HalfbandCoefficients.hpp`; the runtime never designs filters. `Oversampler8x` keeps its public API (`upsample`/`downsample`/`reset`/`latency_samples`) so the product modules change only where the JCM800 tone stack moves inside the single region. Regression snapshots become 1 s golden `.f32` files compared by RMS residual.

**Tech Stack:** C++17, GoogleTest (existing `sushidsp_tests` binary), `SushiDSP::Fft`, Python 3 + numpy + scipy (design-time only, never in CI), LTspice ASCII schematics (`.asc`) authored as text.

**Spec:** `docs/superpowers/specs/2026-08-26-aaa-audio-quality-design.md` — Phase D6a (§D6a.1–D6a.4, "Tests / acceptance") and the "Acceptance summary" table.

### Rulings taken while writing this plan (spec deviations, all tighter or forced)

1. **Stages 2 and 3 are designed to ≥ 90 dB, not the spec's ≥ 80 dB.** Every stage's stopband folds directly into the audio band on the decimation side, so an 80 dB stage caps the cascade at 80 dB and the "≥ 90 dB" acceptance could not be met. The extra taps (~27 and ~19 instead of 23 and 15) run at 4× and 8× with half the taps zero; cost is negligible.
2. **Tap counts are outputs of the design script, not inputs.** The spec's "≈ 63 taps" for stage 1 is an estimate; a 0.05·f_base transition at 90 dB needs ≈ 115 taps. The binding numbers are the band edges and the stopband.
3. **LTspice is not installed on the development machine** (checked 2026-08-26). Task 6 delivers the schematics, the `.subckt` models, the export script, the README and a CSV reader with a fixture, but the golden CSVs themselves are generated by the user after installing LTspice (free). D6b/D6c/D6d nulls consume them; nothing in D6a does.
4. **scipy is not installed system-wide.** Task 1's implementer creates a throw-away venv in the scratchpad; only the generated header is committed. The header's comment block records the exact scipy/numpy versions and the script invocation.
5. **Golden files are pinned before the behaviour changes** (Task 3), then regenerated by Task 4 and Task 5 with the regeneration reason written into the commit message and `tests/golden/README.md`. Regeneration is `SUSHIDSP_REGENERATE_GOLDEN=1 sd test -s regression`.
6. **Polyphase equivalence is asserted to 1e-6, not bit-identical.** The new symmetric-pair summation changes float association order; the old bit-identity test is replaced.
7. **`JcmToneStack` runs at 8× with its existing float biquads.** Coefficient sensitivity at fs/f0 ≈ 3840 was estimated at ≈ 0.01 dB gain error; Task 5 asserts ≤ 0.2 dB against the 48 kHz stack. If that assertion fails, the fix is `double` state in `Biquad`, and the implementer reports BLOCKED rather than loosening the tolerance.

```python
"""Design the three SushiDSP halfband stages with Parks-McClellan and emit the C++ header.

Usage:  python tools/dsp/design_halfband.py > include/SushiDSP/math/HalfbandCoefficients.hpp

Halfband structure is enforced exactly after the equiripple design: every odd-offset tap is
set to 0 and the centre tap to 0.5, then the remaining taps are rescaled so the DC gain is
exactly 1. The response is re-verified after that enforcement, so the numbers printed in the
header are the committed filter's, not the raw remez output's.
"""
import sys
import numpy as np
import scipy
from scipy.signal import remez, freqz

STAGES = [
    ("kHalfbandStage1", 0.225,   90.0, "base <-> 2x, runs at 2*f_base; passband 0.45*f_base, stopband 0.55*f_base"),
    ("kHalfbandStage2", 0.1375,  90.0, "2x <-> 4x, runs at 4*f_base; passes 0.55*f_base, rejects its image at 1.45*f_base"),
    ("kHalfbandStage3", 0.06875, 90.0, "4x <-> 8x, runs at 8*f_base; passes 0.55*f_base, rejects its image at 3.45*f_base"),
]
GRID = 1 << 16


def enforce_halfband(h):
    n = len(h)
    centre = (n - 1) // 2
    h = h.copy()
    for i in range(n):
        if (i - centre) % 2 != 0 and i != centre:
            h[i] = 0.0
    h[centre] = 0.5
    others = h.sum() - 0.5
    scale = 0.5 / others
    for i in range(n):
        if i != centre:
            h[i] *= scale
    return h


def measure(h, passband_edge):
    w, response = freqz(h, worN=GRID, fs=1.0)
    magnitude_db = 20.0 * np.log10(np.maximum(np.abs(response), 1e-300))
    stop = magnitude_db[w >= 0.5 - passband_edge].max()
    ripple = np.abs(magnitude_db[w <= passband_edge]).max()
    return stop, ripple


def design(passband_edge, stopband_db):
    for m in range(2, 128):
        n = 4 * m - 1
        h = remez(n, [0.0, passband_edge, 0.5 - passband_edge, 0.5], [1.0, 0.0], fs=1.0,
                  maxiter=200, grid_density=32)
        h = enforce_halfband(h)
        stop, ripple = measure(h, passband_edge)
        if stop <= -stopband_db:
            return h, n, stop, ripple
    raise RuntimeError("no halfband length up to 511 taps met the stopband")


def emit(out):
    header = open("include/SushiDSP/core/PortLayout.hpp", encoding="utf-8").read().split("\n")
    licence = header[:22]
    name_line = "/* HalfbandCoefficients.hpp"
    licence[1] = name_line + " " * (76 - len(name_line) - 2) + "*/"
    out.write("\n".join(licence) + "\n\n")
    out.write("// GENERATED by tools/dsp/design_halfband.py - do not edit by hand.\n")
    out.write(f"// scipy {scipy.__version__}, numpy {np.__version__}, remez grid_density=32, verification grid {GRID}.\n\n")
    out.write("#pragma once\n\n#include <cstdint>\n\nnamespace SushiDSP\n{\n")
    out.write("    /// @brief One halfband FIR stage: full symmetric impulse response with the zero taps\n")
    out.write("    /// stored as exact zeros and the centre tap exactly 0.5. Band edges are normalised to\n")
    out.write("    /// the stage's own higher sample rate.\n")
    out.write("    struct HalfbandDesign\n    {\n        const float*  taps;\n        std::uint32_t tap_count;\n")
    out.write("        float         passband_edge;\n        float         stopband_db;\n    };\n\n")
    for name, edge, want, note in STAGES:
        h, n, stop, ripple = design(edge, want)
        out.write(f"    // {note}\n")
        out.write(f"    // {n} taps; measured stopband {stop:.2f} dB, passband ripple {ripple:.5f} dB\n")
        out.write(f"    inline constexpr float {name}Taps[{n}] =\n    {{\n")
        for i in range(0, n, 4):
            row = ", ".join(f"{float(np.float32(v)):.9e}f" for v in h[i:i + 4])
            out.write(f"        {row},\n")
        out.write("    };\n")
        out.write(f"    inline constexpr HalfbandDesign {name}{{ {name}Taps, {n}u, {edge}f, {stop:.3f}f }};\n\n")
        print(f"{name}: {n} taps, stopband {stop:.2f} dB, ripple {ripple:.5f} dB", file=sys.stderr)
    out.write("}\n")


if __name__ == "__main__":
    emit(sys.stdout)
```

```cpp
/* LICENSE HEADER — copy from PortLayout.hpp, filename line changed */

#define _USE_MATH_DEFINES
#include <algorithm>
#include <cmath>
#include <cstdint>
#include <cstdio>
#include <vector>

#include <gtest/gtest.h>

#include "SushiDSP/core/IAudioNode.hpp"
#include "measure/AliasFloor.hpp"
#include "measure/FrequencyResponse.hpp"
#include "measure/NullTest.hpp"
#include "measure/Render.hpp"
#include "measure/Spectrum.hpp"
#include "measure/Thd.hpp"

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

namespace
{
    /// @brief y = tanh(g x): a known nonlinearity whose harmonic series is easy to bound.
    class TanhNode : public SushiDSP::IAudioNode
    {
    public:
        explicit TanhNode(float gain) : gain_(gain) {}
        void prepare(const SushiDSP::PrepareInfo&) override {}
        void process(SushiDSP::ProcessContext& context) override
        {
            for (std::uint32_t i = 0; i < context.frames; ++i)
            {
                context.outputs[0][i] = std::tanh(gain_ * context.inputs[0][i]);
            }
        }
        void reset() override {}
    private:
        float gain_;
    };

    class IdentityNode : public SushiDSP::IAudioNode
    {
    public:
        void prepare(const SushiDSP::PrepareInfo&) override {}
        void process(SushiDSP::ProcessContext& context) override
        {
            for (std::uint32_t i = 0; i < context.frames; ++i)
            {
                context.outputs[0][i] = context.inputs[0][i];
            }
        }
        void reset() override {}
    };

    /// @brief y = x - x^3/3: third harmonic (A^3/12) / (A - A^3/4) of the fundamental.
    class CubicNode : public SushiDSP::IAudioNode
    {
    public:
        void prepare(const SushiDSP::PrepareInfo&) override {}
        void process(SushiDSP::ProcessContext& context) override
        {
            for (std::uint32_t i = 0; i < context.frames; ++i)
            {
                const float x = context.inputs[0][i];
                context.outputs[0][i] = x - x * x * x / 3.0f;
            }
        }
        void reset() override {}
    };

    /// @brief First-order lowpass at 1 kHz: -3.01 dB at 1 kHz, -20.04 dB at 10 kHz (analytic RC).
    class OnePoleNode : public SushiDSP::IAudioNode
    {
    public:
        void prepare(const SushiDSP::PrepareInfo& info) override
        {
            coefficient_ = static_cast<float>(std::exp(-2.0 * M_PI * 1000.0 / info.sample_rate));
        }
        void process(SushiDSP::ProcessContext& context) override
        {
            for (std::uint32_t i = 0; i < context.frames; ++i)
            {
                state_ = (1.0f - coefficient_) * context.inputs[0][i] + coefficient_ * state_;
                context.outputs[0][i] = state_;
            }
        }
        void reset() override { state_ = 0.0f; }
    private:
        float coefficient_ = 0.0f;
        float state_ = 0.0f;
    };
}

TEST(Unit_Dsp, MeasureSpectrumFloorOfPureSineIsBelowMinus110dB)
{
    const double sample_rate = 48000.0;
    const double f0 = SushiDSP::measure::bin_exact_frequency(1000.0, sample_rate, SushiDSP::measure::kFftSize);
    const auto signal = SushiDSP::measure::sine_stimulus(f0, sample_rate, SushiDSP::measure::kFftSize, 0.5f);
    const auto spectrum = SushiDSP::measure::magnitude_spectrum_db(signal, 0);
    const std::uint32_t fundamental_bin = SushiDSP::measure::bin_of(f0, sample_rate);
    double worst = -300.0;
    for (std::uint32_t bin = 8; bin < spectrum.size(); ++bin)
    {
        if (bin + 8 > fundamental_bin && bin < fundamental_bin + 8)
        {
            continue;
        }
        worst = std::max(worst, spectrum[bin] - spectrum[fundamental_bin]);
    }
    EXPECT_LE(worst, -110.0);
}
```

```cpp
#pragma once

#include <algorithm>
#include <cmath>
#include <cstdint>
#include <vector>

#include "SushiDSP/math/Fft.hpp"
#include "measure/Window.hpp"

namespace SushiDSP::measure
{
    inline constexpr std::uint32_t kFftSize = 65536;

    /// @brief Nearest frequency whose period divides fft_size exactly, so a windowed FFT of
    /// that tone puts all its energy at one bin's centre.
    /// @param frequency_hz Requested frequency.
    /// @param sample_rate Sample rate.
    /// @param fft_size Analysis length.
    /// @return The snapped frequency in Hz.
    inline double bin_exact_frequency(double frequency_hz, double sample_rate, std::uint32_t fft_size)
    {
        return std::round(frequency_hz * fft_size / sample_rate) * sample_rate / fft_size;
    }

    /// @brief Bin index of a frequency at kFftSize.
    /// @param frequency_hz Frequency.
    /// @param sample_rate Sample rate.
    /// @return Rounded bin index.
    inline std::uint32_t bin_of(double frequency_hz, double sample_rate)
    {
        return static_cast<std::uint32_t>(std::lround(frequency_hz * kFftSize / sample_rate));
    }

    /// @brief Blackman-Harris windowed magnitude spectrum of signal[offset, offset + kFftSize).
    /// @param signal Input, at least offset + kFftSize samples.
    /// @param offset First sample analysed (skip a node's settling time).
    /// @return kFftSize/2 + 1 magnitudes in dB (unnormalised; use differences between bins).
    inline std::vector<double> magnitude_spectrum_db(const std::vector<float>& signal, std::size_t offset)
    {
        static const std::vector<float> window = blackman_harris(kFftSize);
        static const Fft fft(kFftSize);
        std::vector<float> frame(kFftSize), real(kFftSize), imaginary(kFftSize);
        for (std::uint32_t i = 0; i < kFftSize; ++i)
        {
            frame[i] = signal[offset + i] * window[i];
        }
        fft.forward(frame.data(), real.data(), imaginary.data());
        std::vector<double> magnitude(kFftSize / 2 + 1);
        for (std::uint32_t bin = 0; bin < magnitude.size(); ++bin)
        {
            const double power = static_cast<double>(real[bin]) * real[bin] + static_cast<double>(imaginary[bin]) * imaginary[bin];
            magnitude[bin] = 10.0 * std::log10(std::max(power, 1e-300));
        }
        return magnitude;
    }

    /// @brief Highest magnitude within +-half_width bins of centre (the window's main lobe).
    /// @param spectrum From magnitude_spectrum_db.
    /// @param centre Bin index.
    /// @param half_width Bins each side to search; 4 covers a Blackman-Harris main lobe.
    /// @return Peak magnitude in dB.
    inline double peak_near(const std::vector<double>& spectrum, std::uint32_t centre, std::uint32_t half_width = 4)
    {
        const std::uint32_t first = centre > half_width ? centre - half_width : 0;
        const std::uint32_t last = std::min<std::uint32_t>(centre + half_width, static_cast<std::uint32_t>(spectrum.size() - 1));
        double peak = -300.0;
        for (std::uint32_t bin = first; bin <= last; ++bin)
        {
            peak = std::max(peak, spectrum[bin]);
        }
        return peak;
    }
}
```

```cpp
#include <algorithm>

#define M_PI 3.14159265358979323846
#endif

namespace SushiDSP::measure

    /// @brief Prepares a node and streams a stimulus through it block by block.
    /// @param node Any mono node; its knobs should already be set so prepare() snaps them.
    /// @param stimulus Input samples.
    /// @param sample_rate Rate passed to prepare().
    /// @param block_size Maximum block passed to prepare() and used for every full block.
    /// @return The node's output, stimulus.size() samples.
    inline std::vector<float> render(IAudioNode& node, const std::vector<float>& stimulus, double sample_rate, std::uint32_t block_size)
    {
        node.prepare({ sample_rate, block_size, 1 });
        std::vector<float> output(stimulus.size(), 0.0f);
        std::size_t position = 0;
        while (position < stimulus.size())
        {
            const std::uint32_t frames = static_cast<std::uint32_t>(std::min<std::size_t>(block_size, stimulus.size() - position));
            const float* inputs[1] = { stimulus.data() + position };
            float* outputs[1] = { output.data() + position };
            ProcessContext context{ outputs, inputs, frames, static_cast<double>(position) / sample_rate };
            node.process(context);
            position += frames;
        }
        return output;
    }

    /// @brief Sine of `length` samples.
    /// @param frequency_hz Frequency.
    /// @param sample_rate Sample rate.
    /// @param length Number of samples.
    /// @param amplitude Peak amplitude.
    /// @return The samples.
    inline std::vector<float> sine_stimulus(double frequency_hz, double sample_rate, std::size_t length, float amplitude)
    {
        std::vector<float> signal(length);
        for (std::size_t i = 0; i < length; ++i)
        {
            signal[i] = amplitude * static_cast<float>(std::sin(2.0 * M_PI * frequency_hz * static_cast<double>(i) / sample_rate));
        }
        return signal;
    }
}
```

```cpp
    struct ThdResult
    {
        double              thd_percent;
        std::vector<double> per_harmonic_db;   // index k-1 holds harmonic k relative to the fundamental; index 0 is 0 dB

    /// @brief THD of a steady-state signal at a bin-exact fundamental.
    /// @param signal At least kFftSize samples; the last kFftSize are analysed.
    /// @param f0 Fundamental in Hz (use bin_exact_frequency).
    /// @param sample_rate Sample rate.
    /// @param harmonics Number of harmonics reported, including the fundamental.
    /// @return THD in percent and each harmonic's level relative to the fundamental
    ///         (-300 for harmonics above Nyquist).
    inline ThdResult thd(const std::vector<float>& signal, double f0, double sample_rate, std::uint32_t harmonics = 20)
    {
        const auto spectrum = magnitude_spectrum_db(signal, signal.size() - kFftSize);
        const double fundamental = peak_near(spectrum, bin_of(f0, sample_rate));
        ThdResult result{ 0.0, {} };
        double harmonic_power = 0.0;
        for (std::uint32_t k = 1; k <= harmonics; ++k)
        {
            const double frequency = f0 * k;
            if (frequency >= sample_rate / 2.0)
            {
                result.per_harmonic_db.push_back(-300.0);
                continue;
            }
            const double level = peak_near(spectrum, bin_of(frequency, sample_rate)) - fundamental;
            result.per_harmonic_db.push_back(level);
            if (k > 1)
            {
                harmonic_power += std::pow(10.0, level / 10.0);
            }
        }
        result.thd_percent = 100.0 * std::sqrt(harmonic_power);
        return result;
```

```cpp
    /// @brief Worst non-harmonic spectral line produced by a node across 1..20 kHz test tones.
    ///
    /// Each tone is bin-exact, at -12 dBFS, rendered for one second of settling plus one
    /// analysis frame. Lines within four bins of DC, of the fundamental, or of any harmonic
    /// below Nyquist are excluded; a harmonic that would fall above Nyquist has folded back and
    /// is counted as an alias, which is what the number is for.
    /// @param node The node under test, knobs already set.
    /// @param sample_rate Sample rate.
    /// @return Worst alias level in dB relative to the fundamental (more negative is better).
    inline double alias_floor(IAudioNode& node, double sample_rate)
    {
        constexpr float amplitude = 0.251189f;   // -12 dBFS
        const std::size_t settle = static_cast<std::size_t>(sample_rate);
        const std::uint32_t low_bin = bin_of(20.0, sample_rate);
        const std::uint32_t high_bin = bin_of(std::min(20000.0, sample_rate / 2.0 - 1.0), sample_rate);
        double worst = -300.0;
        for (double tone = 1000.0; tone <= 20000.0 + 1e-9; tone += 1000.0)
        {
            const double f0 = bin_exact_frequency(tone, sample_rate, kFftSize);
            node.reset();
            const auto output = render(node, sine_stimulus(f0, sample_rate, settle + kFftSize, amplitude), sample_rate, 256);
            const auto spectrum = magnitude_spectrum_db(output, settle);
            const double fundamental = peak_near(spectrum, bin_of(f0, sample_rate));
            std::vector<bool> masked(spectrum.size(), false);
            auto mask = [&](std::uint32_t centre)
            {
                for (std::uint32_t bin = centre > 4 ? centre - 4 : 0; bin <= centre + 4 && bin < masked.size(); ++bin)
                {
                    masked[bin] = true;
                }
            };
            mask(0);
            for (double harmonic = f0; harmonic < sample_rate / 2.0; harmonic += f0)
            {
                mask(bin_of(harmonic, sample_rate));
            }
            for (std::uint32_t bin = low_bin; bin <= high_bin; ++bin)
            {
                if (!masked[bin])
                {
                    worst = std::max(worst, spectrum[bin] - fundamental);
                }
            }
        }
        return worst;
    }
}
```

```cpp
/* LICENSE HEADER — copy from PortLayout.hpp, filename line changed */

#pragma once

#include <algorithm>
#include <cmath>
#include <cstdint>
#include <vector>

#include "SushiDSP/core/IAudioNode.hpp"
#include "SushiDSP/math/Fft.hpp"
#include "measure/Render.hpp"

namespace SushiDSP::measure
{
    struct ResponsePoint
    {
        double frequency_hz;
        double magnitude_db;
    };

    /// @brief Small-signal magnitude response by exponential sine sweep and deconvolution.
    ///
    /// Sweep 20 Hz -> sample_rate/2 over two seconds at -40 dBFS, followed by one second of
    /// silence for the tail. The inverse filter is the time-reversed sweep with a 6 dB/octave
    /// amplitude envelope (Farina); the linear impulse response is the circular convolution
    /// of output and inverse. Harmonic products land before the linear response and are
    /// excluded by keeping only the causal second. The stimulus itself is deconvolved the same
    /// way and used as the 0 dB reference.
    /// @param node The node under test, knobs already set.
    /// @param sample_rate Sample rate.
    /// @param frequencies_hz Frequencies to report.
    /// @return One point per requested frequency.
    inline std::vector<ResponsePoint> frequency_response(IAudioNode& node, double sample_rate, const std::vector<double>& frequencies_hz)
    {
        const double sweep_seconds = 2.0;
        const double f1 = 20.0;
        const double f2 = sample_rate / 2.0;
        const std::size_t sweep_length = static_cast<std::size_t>(sweep_seconds * sample_rate);
        const std::size_t total_length = sweep_length + static_cast<std::size_t>(sample_rate);
        const double rate = std::log(f2 / f1);
        constexpr float amplitude = 0.01f;   // -40 dBFS

        std::vector<float> sweep(total_length, 0.0f);
        for (std::size_t n = 0; n < sweep_length; ++n)
        {
            const double t = static_cast<double>(n) / sample_rate;
            sweep[n] = amplitude * static_cast<float>(std::sin(2.0 * M_PI * f1 * sweep_seconds / rate * (std::exp(t * rate / sweep_seconds) - 1.0)));
        }

        std::uint32_t fft_size = 1;
        while (fft_size < 2 * total_length)
        {
            fft_size *= 2;
        }
        const Fft fft(fft_size);

        auto spectrum_of = [&](const std::vector<float>& signal, std::vector<float>& real, std::vector<float>& imaginary)
        {
            std::vector<float> padded(fft_size, 0.0f);
            std::copy(signal.begin(), signal.end(), padded.begin());
            real.assign(fft_size, 0.0f);
            imaginary.assign(fft_size, 0.0f);
            fft.forward(padded.data(), real.data(), imaginary.data());
        };

        std::vector<float> inverse(total_length, 0.0f);
        for (std::size_t n = 0; n < sweep_length; ++n)
        {
            const double t = static_cast<double>(n) / sample_rate;
            inverse[sweep_length - 1 - n] = sweep[n] * static_cast<float>(std::exp(-t * rate / sweep_seconds));
        }
        std::vector<float> inverse_real, inverse_imaginary;
        spectrum_of(inverse, inverse_real, inverse_imaginary);

        auto impulse_of = [&](const std::vector<float>& signal)
        {
            std::vector<float> signal_real, signal_imaginary;
            spectrum_of(signal, signal_real, signal_imaginary);
            std::vector<float> product_real(fft_size), product_imaginary(fft_size);
            for (std::uint32_t k = 0; k < fft_size; ++k)
            {
                product_real[k] = signal_real[k] * inverse_real[k] - signal_imaginary[k] * inverse_imaginary[k];
                product_imaginary[k] = signal_real[k] * inverse_imaginary[k] + signal_imaginary[k] * inverse_real[k];
            }
            std::vector<float> impulse(fft_size);
            fft.inverse(product_real.data(), product_imaginary.data(), impulse.data());
            // The linear response begins at index sweep_length - 1; keep one second from there.
            std::vector<float> causal(static_cast<std::size_t>(sample_rate), 0.0f);
            for (std::size_t i = 0; i < causal.size(); ++i)
            {
                causal[i] = impulse[sweep_length - 1 + i];
            }
            return causal;
        };

        const auto reference = impulse_of(sweep);
        node.reset();
        const auto measured = impulse_of(render(node, sweep, sample_rate, 256));

        std::vector<float> reference_real, reference_imaginary, measured_real, measured_imaginary;
        spectrum_of(reference, reference_real, reference_imaginary);
        spectrum_of(measured, measured_real, measured_imaginary);

        std::vector<ResponsePoint> points;
        for (const double frequency : frequencies_hz)
        {
            const std::uint32_t bin = static_cast<std::uint32_t>(std::lround(frequency * fft_size / sample_rate));
            const double reference_power = static_cast<double>(reference_real[bin]) * reference_real[bin] + static_cast<double>(reference_imaginary[bin]) * reference_imaginary[bin];
            const double measured_power = static_cast<double>(measured_real[bin]) * measured_real[bin] + static_cast<double>(measured_imaginary[bin]) * measured_imaginary[bin];
            points.push_back({ frequency, 10.0 * std::log10(measured_power / reference_power) });
        }
        return points;
    }
}
```

```cpp
#pragma once

#include <algorithm>
#include <cmath>
#include <cstdint>
#include <vector>

namespace SushiDSP::measure
{
    /// @brief Residual of b against a after integer-delay and least-squares gain alignment.
    ///
    /// The lag is the integer in [-max_lag, max_lag] maximising the cross-correlation; the
    /// gain is the least-squares scalar over the overlapping region. The residual is
    /// 20*log10(rms(a - g*b_shifted) / rms(a)). Cost is O(length * max_lag): pass a small
    /// max_lag when the delay is known to be small.
    /// @param a Reference signal.
    /// @param b Signal under test.
    /// @param max_lag Largest delay searched, in samples.
    /// @return Residual in dB (negative; -200 when the residual is exactly zero).
    inline double null_test(const std::vector<float>& a, const std::vector<float>& b, std::uint32_t max_lag = 4096)
    {
        const std::size_t length = std::min(a.size(), b.size());
        long best_lag = 0;
        double best_correlation = -1e300;
        for (long lag = -static_cast<long>(max_lag); lag <= static_cast<long>(max_lag); ++lag)
        {
            double correlation = 0.0;
            for (std::size_t i = 0; i < length; ++i)
            {
                const long j = static_cast<long>(i) - lag;
                if (j >= 0 && j < static_cast<long>(length))
                {
                    correlation += static_cast<double>(a[i]) * b[static_cast<std::size_t>(j)];
                }
            }
            if (correlation > best_correlation)
            {
                best_correlation = correlation;
                best_lag = lag;
            }
        }
        double ab = 0.0, bb = 0.0, aa = 0.0;
        for (std::size_t i = 0; i < length; ++i)
        {
            const long j = static_cast<long>(i) - best_lag;
            if (j >= 0 && j < static_cast<long>(length))
            {
                const double bj = b[static_cast<std::size_t>(j)];
                ab += static_cast<double>(a[i]) * bj;
                bb += bj * bj;
                aa += static_cast<double>(a[i]) * a[i];
            }
        }
        const double gain = bb > 0.0 ? ab / bb : 0.0;
        double residual = 0.0;
        for (std::size_t i = 0; i < length; ++i)
        {
            const long j = static_cast<long>(i) - best_lag;
            const double aligned = (j >= 0 && j < static_cast<long>(length)) ? gain * b[static_cast<std::size_t>(j)] : 0.0;
            const double difference = static_cast<double>(a[i]) - aligned;
            residual += difference * difference;
        }
        if (residual <= 0.0 || aa <= 0.0)
        {
            return -200.0;
        }
        return 10.0 * std::log10(residual / aa);
    }
}
```

```cpp
    /// @brief RMS residual of b against a, in dB relative to a's RMS; no alignment, since a
    /// golden file and its regeneration share every delay.
    /// @param a Golden samples.
    /// @param b Rendered samples.
    /// @return 20*log10(rms(a-b)/rms(a)), or -200 when identical.
    inline double residual_db(const std::vector<float>& a, const std::vector<float>& b)
    {
        double difference = 0.0, reference = 0.0;
        for (std::size_t i = 0; i < a.size() && i < b.size(); ++i)
        {
            const double d = static_cast<double>(a[i]) - b[i];
            difference += d * d;
            reference += static_cast<double>(a[i]) * a[i];
        }
        if (difference <= 0.0 || reference <= 0.0)
        {
            return -200.0;
        }
        return 10.0 * std::log10(difference / reference);
    }

    /// @brief Compares rendered output with tests/golden/<name>.f32, or rewrites that file
    /// when SUSHIDSP_REGENERATE_GOLDEN is set in the environment.
    /// @param name File stem, e.g. "jcm800_48k".
    /// @param rendered The node's output for stimulus().
    /// @return Residual in dB; -200 after a regeneration; 0 when the file is missing or short.
    inline double compare_or_regenerate(const char* name, const std::vector<float>& rendered)
    {
        const std::string path = std::string(SUSHIDSP_GOLDEN_DIR) + "/" + name + ".f32";
        if (std::getenv("SUSHIDSP_REGENERATE_GOLDEN") != nullptr)
        {
            std::FILE* file = std::fopen(path.c_str(), "wb");
            if (file == nullptr)
            {
                return 0.0;
            }
            std::fwrite(rendered.data(), sizeof(float), rendered.size(), file);
            std::fclose(file);
            return -200.0;
        }
        std::FILE* file = std::fopen(path.c_str(), "rb");
        if (file == nullptr)
        {
            return 0.0;
        }
        std::vector<float> stored(rendered.size(), 0.0f);
        const std::size_t read = std::fread(stored.data(), sizeof(float), stored.size(), file);
        std::fclose(file);
        if (read != rendered.size())
        {
            return 0.0;
        }
        return residual_db(stored, rendered);
    }
}
```

```cpp
    void HalfbandUpsampler2x::process(const float* input, std::uint32_t frames, float* output)
    {
        // tap_count = 4M-1, centre index 2M-1. The zero-stuffed input has x_s[2n] = 2 x[n].
        // Output 2n+1 (odd) sees only odd-indexed taps, all zero but the centre 0.5, so it is
        // 2 * 0.5 * x[n - (M-1)] = x[n - centre_delay_]. Output 2n (even) sees the even-indexed
        // taps h[2j] against x[n - j]; pair k (offsets centre -+ (2k+1)) lands on base-rate
        // offsets centre_delay_ - k and centre_delay_ + k + 1.
        const std::uint32_t pair_count = static_cast<std::uint32_t>(pair_coefficients_.size());
        for (std::uint32_t frame = 0; frame < frames; ++frame)
        {
            write_index_ = (write_index_ + 1) & history_mask_;
            history_[write_index_] = input[frame];

            float accumulator = 0.0f;
            for (std::uint32_t k = 0; k < pair_count; ++k)
            {
                const float newer = history_[(write_index_ - (centre_delay_ - k)) & history_mask_];
                const float older = history_[(write_index_ - (centre_delay_ + k + 1)) & history_mask_];
                accumulator += pair_coefficients_[k] * (newer + older);
```

```cpp
                }
                output[output_index++] = accumulator;
            }
        }
    }
```
